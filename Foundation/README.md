A Python-based program that analyzes student marks and generates a performance report.

### Features

- Calculate student averages
- Categorize student performance
- Store structured results
- Identify the top-performing student
- Find unique performance categories

```text
======================= Student Performance Analyzer =======================

Ritesh 85.0 Excellent
Amit 71.66666666666667 Good
Rahul 91.33333333333333 Excellent
Priya 68.0 Good

Top Student: Rahul
Highest Average: 91.33333333333333
Unique Categories: {'Excellent', 'Good'}
