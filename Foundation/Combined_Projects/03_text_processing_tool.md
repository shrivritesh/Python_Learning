# 🐍 Text Processing Tool

## 📌 Description

A Python CLI application that analyzes and processes user-provided text using
string methods, loops, and conditionals.

## 🎯 Features

- Clean and normalize text
- Count characters and words
- Search and count word occurrences
- Replace words
- Count vowels and consonants
- Count uppercase, lowercase, and digits
- Reverse text using a loop
- Check palindrome

## 🧠 Concepts Used

- Strings
- String methods
- `strip()`
- `lower()`
- `split()`
- `find()`
- `count()`
- `replace()`
- `islower()`
- `isupper()`
- `isdigit()`
- `for` loops
- `if / elif / else`
- Variables and counters
